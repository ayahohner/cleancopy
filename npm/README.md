# @innerlattice/proseclean

Deterministic checks for English prose, aimed at the habits of LLM-written
text. proseclean is a Python program; this package runs the
[PyPI release](https://pypi.org/project/proseclean/) of the same version
through [uv](https://docs.astral.sh/uv/), which must be installed.

```sh
npx @innerlattice/proseclean post.md
```

The rules, options, and configuration are in the
[proseclean README](https://github.com/ayahohner/proseclean#readme).
