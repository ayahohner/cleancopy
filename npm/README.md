# @innerlattice/cleancopy

Deterministic checks for English prose, aimed at the habits of LLM-written
text. cleancopy is a Python program; this package runs the
[PyPI release](https://pypi.org/project/cleancopy/) of the same version
through [uv](https://docs.astral.sh/uv/), which must be installed.

```sh
npx @innerlattice/cleancopy post.md
```

The rules, options, and configuration are in the
[cleancopy README](https://github.com/ayahohner/cleancopy#readme).
